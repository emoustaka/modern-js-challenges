# Hotel Automation Core (JavaScript ES6+ & Agile Workflow)

A professional mini-project demonstrating modern JavaScript (ES6+) architecture, clean code practices, and asynchronous data handling tailored for hotel automation systems. 

Developed entirely using a solo **Agile/Scrum workflow** with Kanban management.

## 🚀 Key Features Implemented
* **Asynchronous Data Handling:** Managed mock server latency and API fetching using `async/await` and Promises, eliminating UI blocking.
* **Robust Error Handling:** Implemented `try/catch` blocks to gracefully handle network errors and database connection failures without crashing the application.
* **Modern ES6+ Syntax:** Utilized Array Methods (`.filter()`, `.map()`, and Method Chaining), Object/Nested Destructuring, Template Literals, and Ternary Operators for clean and scalable code.
* **Code Quality Automation:** Integrated Prettier configuration (`.prettierrc`) for automated and unified code formatting.

## 🛠️ Tech Stack & Tools
* **Language:** JavaScript (ES6+)
* **Runtime:** Node.js
* **IDE:** Visual Studio Code (Chromedeb environment)
* **Version Control:** Git & GitHub (Conventional Commits workflow)
* **Project Management:** Trello (Kanban Board)

## 📊 Agile & Project Management Workflow
Although this was a solo project, it was executed using professional enterprise standards:
1. **Sprint Planning:** Divided into 4 distinct weekly sprints.
2. **Kanban Board:** Managed tasks via Trello through `Backlog`, `In Progress`, `Code Review`, and `Done` states.
3. **Git Branching Strategy:** Never committed directly to `main`. Every feature was developed in an isolated branch, deployed, and merged via Pull Requests.
